💒 우쥬메리미란?

우쥬메리미(WUMM)는 예비 부부를 위한 웨딩 플래너 앱입니다. 파트너와 함께 결혼 준비 과정을 체계적으로 관리하고, 커뮤니티에서 다른 예비 부부들과 정보를 공유할 수 있습니다.

자주 묻는 질문(FAQ)

파트너와 어떻게 연결하나요?

설정 > 커플 정보에서 파트너 코드를 확인하고 공유하세요. 파트너가 해당 코드를 입력하면 자동으로 연결됩니다. 연결 후 모든 데이터가 실시간으로 공유됩니다.

데이터는 어디에 저장되나요?

계정과 웨딩 준비 데이터는 주로 Firebase에 저장되고, 모바일 청첩장·게스트 갤러리 사진은 Cloudflare R2에 저장됩니다. 자세한 처리자는 아래 개인정보처리방침에서 확인할 수 있습니다.

캘린더 동기화는 어떻게 하나요?

설정 > 캘린더에서 동기화를 켜면 웨딩 일정이 디바이스 캘린더에 자동으로 추가됩니다. 캘린더 접근 권한 허용이 필요합니다.

커뮤니티에서 부적절한 콘텐츠를 발견하면?

게시글이나 댓글의 신고 기능을 이용해 주세요. 신고된 콘텐츠는 24시간 내 검토됩니다. 특정 사용자를 차단할 수도 있습니다.

계정을 삭제하려면?

더보기 > 설정 > 데이터에서 계정을 삭제할 수 있습니다. 개인 계정, 작성한 커뮤니티 콘텐츠, 업로드한 공유 파일·사진과 단독 커플 데이터는 삭제됩니다. 파트너가 남아 있으면 공동 웨딩 준비 기록은 비식별화하여 유지할 수 있으며, 삭제한 사용자에게 배정된 항목은 해제됩니다.

소셜 계정으로 로그인할 수 있나요?

네, 이메일/비밀번호와 Apple, Google, Kakao 로그인을 지원합니다.

개인정보처리방침

시행일: 2026년 7월 15일

1. 수집하는 개인정보

  • 계정·로그인: 이메일 주소, 표시 이름, 프로필 이미지, Firebase 사용자 ID, 선택한 Apple·Google·Kakao 로그인 식별자
  • 웨딩 준비·연락처·금융 정보: 커플 연결 정보, 체크리스트, 예산·결제수단·결제 내역, 일정과 장소, 하객 이름·전화번호·이메일·RSVP·식이 제한·축의금, 업체 담당자·연락처·주소·비용, 청첩장 이름·예식 정보·계좌 안내
  • 사용자 콘텐츠: 커뮤니티 게시글·댓글·사진, 모바일 청첩장·감사 카드·게스트 갤러리 사진, 영수증·계약서와 기타 업로드 파일, 신고 및 피드백 내용
  • 자동 수집: 앱·기기 설치 식별자와 FCM 토큰, 앱/iOS 버전과 기기 모델, 화면·기능 사용 기록, 충돌·진단 데이터, IP 주소와 네트워크·브라우저 정보
  • 공개 웹 페이지: 브랜드·앱 다운로드 연결 페이지와 모바일 청첩장 등 공개 페이지 방문 시 Cloudflare 요청 로그가 처리됩니다. 브랜드·앱 다운로드 연결 페이지에서는 Meta Pixel의 PageView, 브라우저·기기 정보, IP 주소 및 Meta가 설정하는 쿠키·유사 식별자가 처리될 수 있습니다.

2. 개인정보의 처리 목적

  • 회원 관리 및 본인 확인
  • 커플 연동 및 파트너 간 데이터 공유
  • 웨딩 준비 데이터 저장·동기화, 모바일 청첩장·게스트 갤러리 제공
  • 커뮤니티 서비스 제공 및 콘텐츠 관리
  • 푸시 알림 발송 (FCM)
  • 앱 사용 통계, 공개 청첩장 방문·홍보 성과 분석
  • 충돌 진단, 보안·부정 이용 방지, 서비스 안정성 개선
  • 영수증·계약서의 OCR 텍스트에서 업체 정보를 추출
  • 사용자 문의·피드백 처리

3. 외부 처리자와 제공 범위

회사는 개인정보를 판매하지 않습니다. 서비스 운영을 위해 다음 처리자가 필요한 범위에서 정보를 처리합니다.

  • Google Firebase — Auth, Firestore, Storage, Cloud Functions, Analytics, Crashlytics, Cloud Messaging을 통한 로그인, 데이터 저장·동기화, 서버 처리, 사용 분석, 충돌 진단, 푸시 알림. 계정·사용자 콘텐츠·사용/기기 식별자·진단 데이터가 기능에 따라 처리됩니다.
  • Apple 및 Google — 사용자가 선택한 소셜 로그인 인증. 인증 식별자와 제공자가 허용한 이름·이메일·프로필 정보가 처리됩니다.
  • Kakao — 사용자가 선택한 Kakao 로그인 인증과 장소·주소 검색 API 제공. 로그인 시 인증 식별자와 사용자가 허용한 이름·이메일·프로필 정보가 처리됩니다. 장소·주소 검색 시 입력한 검색어와 API 요청에 수반되는 네트워크 요청 메타데이터가 Kakao에 전달되고, 장소 이름·주소·좌표가 검색 결과로 반환됩니다.
  • Cloudflare Workers, R2, Workers AI — 모바일 청첩장 공개 페이지·사진 저장·게스트 업로드 제공, Firebase 토큰 검증, 그리고 온디바이스 OCR로 인식한 영수증/계약서 텍스트의 필드 추출. 사진, OCR 텍스트, IP 주소와 요청 메타데이터가 기능에 따라 처리됩니다. 장소 검색에서 Firebase UID는 Cloudflare 내부의 인증과 사용자별 요청 제한에만 사용되며 Kakao에는 전송되지 않습니다.
  • Slack — 앱 내 피드백과 Crashlytics의 운영용 신규 치명적·비치명적 오류 알림 접수. 피드백에는 메시지, 단방향 해시 사용자 참조, 앱/iOS 버전과 기기 모델이 포함되며 이메일과 표시 이름은 포함되지 않습니다. 오류 알림에는 플랫폼, 이슈 제목·부제, 앱 버전 및 Firebase 콘솔 링크가 포함될 수 있습니다.
  • Meta Pixel — 공개 브랜드·앱 다운로드 연결 페이지의 PageView 및 방문·홍보 성과 분석. Meta는 브라우저·기기 정보, IP 주소, 쿠키·유사 식별자를 자체 정책에 따라 처리할 수 있습니다.

4. 개인정보의 보유 및 파기

  • 계정 삭제 요청이 완료되면 계정·개인 프로필, 삭제한 사용자가 작성한 커뮤니티 게시글·댓글·이미지, 업로드한 공유 파일·사진, 그리고 남은 파트너가 없는 커플의 웨딩 준비 데이터를 삭제합니다. 법적 의무, 보안·분쟁 대응에 필요한 최소 기록은 해당 기간 동안 별도 보관할 수 있습니다.
  • 연결된 파트너가 남아 있는 경우 공동 웨딩 준비 기록은 파트너의 계속 이용을 위해 유지될 수 있습니다. 유지되는 공동 기록의 작성자·업로더 식별자는 비식별 값으로 대체하고, 삭제한 사용자에게 배정된 항목은 해제합니다. 다른 사용자의 커뮤니티 콘텐츠에 남은 좋아요·조회 기록과 구조화된 언급에서도 해당 사용자의 식별자와 이름을 제거하며, 계정 연결과 접근 권한을 해제합니다.
  • 서버는 데이터와 외부 저장소의 삭제·비식별화가 성공한 뒤 최종 서버 단계에서 Firebase Authentication 계정을 삭제하고, 이 단계까지 확인된 경우에만 호출 함수(callable)가 성공을 반환합니다. 앱은 확인된 성공 응답을 받은 뒤 로컬 로그아웃만 수행합니다. 외부 파일 삭제나 최종 단계가 실패하면 성공으로 처리하지 않으며, 사용자는 다시 시도할 수 있습니다.
  • 계정 삭제 시 오래된 Firebase ID 토큰으로 프로필이 다시 생성되는 것을 막기 위해 서버 전용 Firebase UID 삭제 잠금만 보관합니다. 이 잠금에는 프로필·콘텐츠 필드가 없으며 24시간 후 만료되고, Firestore TTL이 통상 그 후 약 24시간 이내에 문서를 제거합니다.
  • 사용이 종료된 모바일 청첩장의 공개 URL 슬러그는 같은 URL의 재사용을 방지하기 위한 tombstone으로 보존합니다. 이 tombstone에서는 청첩장·커플·계정 식별자를 제거합니다.
  • 원본 식별자를 포함하지 않는 해시된 슬러그 충돌 진단 기록은 30일 후 삭제합니다.
  • 청첩장 소유자가 업로드한 청첩장 표지·청첩장 갤러리·감사 카드 사진은 예식일 4일 후 안내하고 7일 후 자동 삭제합니다.
  • 하객이 게스트 갤러리에 올린 사진은 예식일 31일 후 자동 삭제합니다.
  • 예식일이 없는 청첩장과 게스트 갤러리는 청첩장 편집 또는 하객 사진 업로드 중 가장 최근 활동으로부터 180일간 활동이 없을 때까지 보유합니다. 이후 소유자에게 안내하고 최소 3일의 유예기간을 둔 뒤, 소유자와 하객이 올린 사진을 삭제하고 게스트 갤러리를 비활성화합니다. 안내 후 청첩장·갤러리 활동이 발생하거나 예식일을 설정·변경하면 기존 미사용 안내를 취소하고 보유 일정을 다시 계산합니다.
  • Firebase, Cloudflare, Slack, Meta의 백업·보안 로그 등은 각 처리자의 운영·법적 보존기간에 따라 제한적으로 남을 수 있습니다.

5. 이용자의 권리와 동의 철회

  • 개인정보 열람, 수정, 삭제 요청 가능
  • 앱 내 설정에서 이름 수정 및 계정 삭제 가능
  • 푸시 알림은 iOS 설정에서 끌 수 있고, 캘린더 동기화는 앱 설정에서 끄거나 iOS 설정에서 권한을 철회할 수 있습니다.
  • Apple·Google·Kakao 연결은 각 제공자 설정에서 철회할 수 있으며, WUMM 데이터 삭제는 별도로 앱의 계정 삭제를 실행해야 합니다.
  • 공개 브랜드·앱 다운로드 연결 페이지의 Meta Pixel은 브라우저의 추적 방지·쿠키 차단 기능으로 제한할 수 있습니다.
  • 선택적 처리에 대한 동의 철회 또는 추가 권리 요청은 앱 내 피드백으로 접수할 수 있습니다. 서비스 제공에 필수인 처리를 철회하면 계정 삭제가 필요할 수 있습니다.
