💒 우쥬메리미란?

우쥬메리미(WUMM)는 예비 부부를 위한 웨딩 플래너 앱입니다. 파트너와 함께 결혼 준비 과정을 체계적으로 관리하고, 커뮤니티에서 다른 예비 부부들과 정보를 공유할 수 있습니다.

🚀 빠른 시작

  1. 앱을 다운로드하고 회원가입
  2. 파트너 코드를 공유해 커플 연결
  3. 결혼 예정일을 설정
  4. 체크리스트, 예산, 일정 관리 시작!

주요 기능

📋 웨딩 체크리스트

결혼 준비에 필요한 할 일을 체크리스트로 관리하고 진행률을 한눈에 확인하세요.

💰 예산 관리

웨딩 예산을 카테고리별로 관리하고 지출 현황을 파트너와 실시간으로 공유하세요.

📅 웨딩 캘린더

웨딩 관련 일정을 관리하고 디바이스 캘린더에 자동 동기화할 수 있습니다.

💬 커뮤니티

다른 예비 부부들과 웨딩 팁, 후기, 고민을 나눌 수 있는 커뮤니티입니다.

💕 커플 연동

파트너 코드로 쉽게 연결하고, 모든 웨딩 준비 데이터를 실시간으로 공유하세요.

⏰ D-Day 카운트다운

결혼식까지 남은 날짜를 홈 화면에서 바로 확인할 수 있습니다.

👥 하객 관리

하객 명단을 관리하고 인원수를 파악할 수 있습니다.

🏪 업체 관리

웨딩 관련 업체(스드메, 본식 등) 정보를 정리하고 관리하세요.

🔔 알림

중요한 일정과 파트너의 활동을 푸시 알림으로 받아보세요.

자주 묻는 질문(FAQ)

파트너와 어떻게 연결하나요?

설정 > 커플 정보에서 파트너 코드를 확인하고 공유하세요. 파트너가 해당 코드를 입력하면 자동으로 연결됩니다. 연결 후 모든 데이터가 실시간으로 공유됩니다.

데이터는 어디에 저장되나요?

모든 데이터는 Firebase에 암호화되어 안전하게 저장되며, 파트너와 실시간 동기화됩니다.

캘린더 동기화는 어떻게 하나요?

설정 > 캘린더에서 동기화를 켜면 웨딩 일정이 디바이스 캘린더에 자동으로 추가됩니다. 캘린더 접근 권한 허용이 필요합니다.

커뮤니티에서 부적절한 콘텐츠를 발견하면?

게시글이나 댓글의 신고 기능을 이용해 주세요. 신고된 콘텐츠는 24시간 내 검토됩니다. 특정 사용자를 차단할 수도 있습니다.

계정을 삭제하려면?

더보기 > 설정 > 데이터에서 계정 삭제를 요청할 수 있습니다. 삭제 시 모든 데이터가 영구적으로 제거됩니다.

카카오 계정으로 로그인할 수 있나요?

네, 이메일/비밀번호 또는 카카오 계정으로 간편하게 로그인할 수 있습니다.

개인정보처리방침

1. 수집하는 개인정보

  • 회원가입 시: 이메일 주소, 닉네임
  • 카카오 로그인 시: 카카오 계정 정보(이메일, 프로필)
  • 자동 수집: 디바이스 UUID, 플랫폼 정보(iOS), 앱 사용 기록
  • 서비스 이용 시: 체크리스트, 예산, 일정, 하객, 업체 정보, 커뮤니티 게시글
  • 모든 데이터는 Firebase를 통해 암호화되어 저장됩니다

2. 개인정보의 처리 목적

  • 회원 관리 및 본인 확인
  • 커플 연동 및 파트너 간 데이터 공유
  • 웨딩 준비 데이터 저장 및 기기 간 동기화
  • 커뮤니티 서비스 제공 및 콘텐츠 관리
  • 푸시 알림 발송 (FCM)
  • 앱 사용 통계 분석 (Firebase Analytics)
  • 서비스 개선을 위한 사용자 피드백 수집

3. 개인정보의 제3자 제공

  • Firebase (Google)
    제공 항목: 이메일, 사용 데이터, 디바이스 정보
    제공 목적: 데이터 저장, 동기화, 푸시 알림, 통계 분석
    보유 기간: 회원 탈퇴 시까지
  • Kakao
    제공 항목: 카카오 계정 연동 정보
    제공 목적: 소셜 로그인
    보유 기간: 회원 탈퇴 시까지

4. 개인정보의 보유 및 파기

  • 회원 탈퇴 시 즉시 삭제 (법령에 의한 보관 의무 제외)
  • 미사용 계정: 1년 미접속 시 별도 저장 후 파기

5. 이용자의 권리

  • 개인정보 열람, 수정, 삭제 요청 가능
  • 앱 내 설정에서 이름 수정 및 계정 삭제 가능
  • 알림 수신 여부 설정 가능

6. 개인정보 보호책임자

  • 이메일: support@wumm.app

7. 개인정보처리방침 변경
